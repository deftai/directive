section: Fixed
- `directive uninstall` now removes Directive through the package manager before it deletes a `package.json` that install created. Before, npm left a bare `{}` and pnpm failed but uninstall still said it had removed Directive. If the package manager fails, uninstall now keeps `package.json`, names the failure, says "partially finished" and exits non-zero. Closes #5999.
- `directive uninstall` now removes the lines Directive wrote into `.gitattributes`, `.prettierignore`, `greptile.json` and the CodeQL config, and leaves every other line as it was. It also says, without `-v`, whether it kept `core.hooksPath` for another worktree, which Directive data it kept (for example `.deft-cache/` and `.deft-scratch/`), and which registered Git worktrees sit inside the project. Any item it could not remove now makes the result "partially finished". Closes #6007.
