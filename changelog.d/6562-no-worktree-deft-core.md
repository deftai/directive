section: Fixed
- `deft session:start` and `deft session:ready` no longer copy the old `.deft/core` folder into a linked git worktree. Before, each start in a worktree could write hundreds of untracked files back, with no message. Swarm worktree prep no longer copies it either: a worktree whose `package.json` does not pin `@deftai/directive-runtime` now stops with the project install message (`npm install` or `pnpm install`). `deft doctor` no longer suggests `deft session:start` to rebuild `.deft/core`. An existing `.deft/core` is left alone; `directive upgrade` removes it. Refs #6562, #6465.
