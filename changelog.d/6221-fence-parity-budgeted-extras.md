section: Changed
- **Fence parity for extra paths**: the story write fence, membership and the Path-independent `verify:scope-provenance` check now share one extra-path rule under one allowlist authority (the merge-base mint when present, else the brief's concrete `file_scope`). Undeclared source, test and fixture paths spend one allowance (floor 2, cap 5), so a fenced agent can fix an existing test outside `file_scope` without a widen PR. Test and fixture extras are admitted only as modifies of a path on the base; adding, deleting or renaming one outside `file_scope` is refused. Beyond the budget all three checks refuse with the reason token `extra-paths-over-budget`. Glob entries in a brief without a mint no longer admit on their own: a matching path spends the allowance at the write fence and on the Path-independent check. Undeclared paths that are neither source, test nor fixture are still refused at membership and the write fence and still ignored on the Path-independent check (named residual). On success the check lists each extra path with its class and spend (#6221).
