- `directive upgrade` now finishes the `vbrief/` → `xbrief/` move when both folders have content, or when `vbrief/` already carries the `DEPRECATED.md` marker. Leftover files move into `xbrief/` when the destination is free, are skipped when `xbrief/` already has the same content, and are copied as-is to `xbrief/archive/` (as `*.legacy.json`) when they differ. Existing `xbrief/` files are never overwritten, and `vbrief/` is removed, so the upgrade commit passes `verify:xbrief-drift --staged`. `deft migrate:xbrief --keep-legacy` still keeps the marker.
