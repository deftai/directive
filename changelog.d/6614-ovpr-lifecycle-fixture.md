section: Added
- CI now has a no-agent fixture test (`ovpr-fixture` job, advisory for now, plus a Windows job for the missing-packages step). It installs the packed packages into throwaway projects and runs each host's registered hook command the way the host does. It checks that a version bump that changes only the pin and lockfile, followed by a plain project install, is completed by the first hook run; that every host blocks with the project install message once `node_modules` is deleted; and that old-style projects block with the old-project message, or run their own installed copy. Refs #6614, #6621.
