section: Changed
- `directive install`, `install --repair`, `upgrade` and automatic setup now replace Directive's git hooks with the current version, even when they are committed or edited, and name each one: "Updated `<path>`; your earlier version is in git history." The old `_deft-run.sh` helper is removed once no hook uses it. A hook that is not Directive's is still left alone and reported. The install, repair, upgrade and uninstall plans list the git hooks they will write, replace or remove. The `--force-githooks` setup flag is gone. Doctor now checks `.githooks/pre-push`, and reports a missing pre-commit or pre-push next to Directive's hook helper. Refs #5976, #5808.
