section: Changed
- The temporary kill-switch is now a kill record, not a bare file (#6740, slice 1). A root `.deft-directive-disable` file turns nothing off: every hook event, `doctor` and `session:start` print one warning that names the file and the on verb. A person runs `deft kill-switch:on --confirm` at a terminal (kept terminal mint, refused under UAT) to write `.deft/authz/kill-switch.disable`, bound to `git rev-parse --absolute-git-dir`; `deft kill-switch:off --confirm` removes it with no mint. The core, runtime, launcher, outer hook, git-hook helper and Taskfile readers share one whole-line contract and one fixture set; the git-hook helper needs no `node`. The outer hook passes `--kill-switch-reader v1` and the git-hook helper carries a marker; `doctor` reports a deposit without them and names `directive upgrade` or `directive install --repair`. The #6136 plant guard is unchanged. The off switch is as strong as the grant store and the kept mint, no stronger.
