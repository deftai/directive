section: Fixed
- Projects still on an older version of Directive keep working after you install the new global launcher. When the project's own older copy of Directive is installed in its `node_modules`, `deft`, `directive` and `deft-hook` (including `deft hook:dispatch`) now pass every command except `upgrade` and `uninstall` to that copy, so the project stays on its own version until you run `directive upgrade`. A global copy, a copy outside the project or a copy at another version is never run. When the project's copy is not installed, commands stop and agent hooks block the tool call with "This project uses an older version of Directive that isn't installed. Run `npm install` (or `pnpm install`) to keep using it, or run `directive upgrade` to update." Before, Claude Code and Codex hooks saw exit 1 and carried on with no checks. In a project that pins the runtime, a `deft-hook` call now blocks with the project install command when the runtime is missing or at another version. Refs #5960.
