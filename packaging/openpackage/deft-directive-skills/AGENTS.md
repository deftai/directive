# Deft Directive (OpenPackage pointer)

Deft is installed via `@deftai/directive` (`directive install`). Full guidelines: `node_modules/@deftai/directive-runtime/main.md`.

! Before improvising a multi-step workflow, run `directive packs:slice skills list` (text form, not `--json`; local also `.\node_modules\.bin\deft`) and load the matching skill — do not rely on skill enumeration in this file. ⊗ Teach npx / pnpm-exec shortcuts as day-to-day identity (AC9.11 / AC13.8).
