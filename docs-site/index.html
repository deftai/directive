Directive — one-shot, anti-slop development with agents

Deft is the company and on-disk footprint. Directive is the product: a layered framework of standards, skills, and deterministic task tooling so AI-assisted coding stays consistent, auditable, and upgradeable.

Start with three commands — init · update · doctor — then learn the A / B / C concepts, quality gates, and upgrade path.

What it is

Directive is a repo practice layer: shared standards, durable work state, and hard gates in the git tree. It is not a coding host, not only a skill pack, and not an app orchestrator. Read the four-way map in docs/CATEGORY.md before you compare tools by star count.

In practice it turns agent work from chat-only habits into a repeatable loop:

  • Layered guidance agents load only when needed (not one giant prompt).
  • Durable project and scope state in xBRIEF JSON instead of lost chat memory.
  • Deterministic gates (task check, doctor, hooks, CI) instead of “remember to verify” prose.

This site is the public home for install and concepts. Deep detail still lives in the GitHub repository (contributor source of truth). No traction or adoption metrics are claimed here beyond what the public repo and npm package show.

A

Standards that stick

USER.md, project definition, language files, and main.md cascade so agents stop re-learning your preferences every session.

B

Scope you can audit

Work moves through xBRIEF lifecycle folders (proposed → pending → active → completed) with explicit promote / activate / complete verbs.

C

Gates that enforce

task check, branch policy, encoding, and story preflight keep quality out of fragile narrative-only rules.

Three-command model

Situation Command
New or existing codebase, first Directive setup directive init
Already on Directive; refresh the deposit / engine directive update
Not sure, or something looks broken directive doctor

Canonical install is npm: npm i -g @deftai/directive (Node ≥ 20). The deft CLI name remains an alias for directive. Details: Install.
