Install

Install (three commands)

Node ≥ 20 is required to run Directive. The canonical channel is the published npm package @deftai/directive.

  1. Install the engine globally 
    npm i -g @deftai/directive

    pnpm works against the same registry: pnpm add -g @deftai/directive (ensure PNPM_HOME is on PATH).

  2. Initialize the project directory 
    cd /path/to/your-project
directive init

    By default init classifies the current working directory (empty, brownfield app, existing Directive deposit, or legacy layout) and takes exactly one path. Use --repo-root only when you intentionally target another tree.

  3. Confirm with doctor 
    directive doctor

    Read-only diagnosis. Prints exactly one recommended next step.

When to use each command

Command Use when
directive init First-time adoption or layout classification / migration routing.
directive update Existing Directive project: refresh deposit and heal the engine.
directive doctor Any time you need a safe “where am I?” probe.

One-shot without a global install

npx @deftai/directive doctor
npx @deftai/directive init

Alias: deft is the same binary as directive.

What gets committed vs ignored

  • Tracked: your package.json pin (reconstitutes the deposit on a fresh clone), managed AGENTS.md section, project xBRIEF sources you author.
  • Usually gitignored local artifacts: .deft/core/ deposit (when not already tracked as a vendored tree), .deft/.cli/ engine cache, session/ritual state, .deft-cache/.
