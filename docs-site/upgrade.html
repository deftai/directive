Upgrade

Ordinary upgrades are two steps: refresh the global engine, then run directive update in the project. Use doctor when the path is unclear.

Canonical path (npm)

  1. Upgrade the global engine 
    npm i -g @deftai/directive@latest

    pnpm: pnpm add -g @deftai/directive@latest

  2. Refresh the project deposit 
    cd /path/to/your-project
directive update
directive doctor
  3. Start a new agent session

    After a framework update, open a fresh agent session so AGENTS.md and skills are not stale mid-context.

Which command when

  • Ordinary upgrade → directive update after npm latest.
  • Not sure / looks broken → directive doctor (read-only; one next step).
  • First adoption or legacy layout → directive init (classifies and routes).

Multi-version “big jumps”, frozen pre-v0.20 document-model migration, corporate registry lag, and legacy Go-installer bridges are documented in content/UPGRADING.md. Do not invent a third upgrade tool when doctor already names the next command.

Version badge

Public version truth is the published npm package and GitHub releases — not the 0.0.0 placeholders inside the monorepo source tree (those are stamped at release time).
